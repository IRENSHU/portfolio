Что обязательно для сайта школы

Сайт образовательной организации проверяют надзорные органы. Проверяют не красоту, а наличие разделов, структуру адресов и разметку. Вот что заложено в этом демо.

  • Раздел «Сведения об образовательной организации» с подразделами по установленной структуре, каждый по своему адресу
  • Разметка данных, по которой надзорные системы автоматически собирают сведения с сайта
  • Версия для слабовидящих: размеры текста, три цветовые схемы, интервалы, отключение изображений
  • Управление только с клавиатуры и видимая рамка фокуса — без мыши сайт остаётся рабочим
  • Документы отдельными файлами, с датами и понятными названиями
  • Формы обращений с отдельным согласием на обработку персональных данных
  • Размещение на серверах в России
  • Быстрая загрузка: сайт открывается и на школьном компьютере с медленным интернетом

Важно: перечень и структура подразделов меняются, поэтому перед сдачей я сверяю их с действующей редакцией приказа, а не делаю по памяти или по чужому сайту.
