## Как это сделано

- Чистые HTML, CSS и JavaScript — без конструкторов, препроцессоров и фреймворков
- Сетки на CSS Grid и Flexbox, без абсолютного позиционирования в основной структуре
- Mobile-first: базовые стили под телефон, `min-width` медиазапросы добавляют колонки
- Проверка на ширинах 375, 768, 1024 и 1280 — без горизонтальной прокрутки
- Формы с проверкой полей и понятными сообщениями об ошибках
- Семантическая разметка, `aria`-атрибуты, видимый фокус для клавиатуры
