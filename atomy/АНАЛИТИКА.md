# 📊 Как подключить Яндекс.Метрику (статистика сайта)

Метрика показывает: сколько людей зашло, с каких страниц, откуда пришли, сколько кликнули по кнопкам/формам. Бесплатно.

## Шаг 1. Создать счётчик
1. Зайди на **metrika.yandex.ru** под своим Яндекс-аккаунтом.
2. Нажми **«Добавить счётчик»**, укажи адрес сайта (появится после публикации).
3. Скопируй **номер счётчика** (например, `99999999`) и готовый код.

## Шаг 2. Вставить код на сайт
Код Метрики нужно вставить **перед закрывающим тегом `</body>`** на каждой странице (или скажи мне номер счётчика — вставлю на все 11 страниц сам за минуту).

Готовый шаблон (вставь свой номер вместо `XXXXXXXX`):

```html
<!-- Yandex.Metrika counter -->
<script type="text/javascript">
   (function(m,e,t,r,i,k,a){m[i]=m[i]||function(){(m[i].a=m[i].a||[]).push(arguments)};
   m[i].l=1*new Date();k=e.createElement(t),a=e.getElementsByTagName(t)[0],k.async=1,k.src=r,a.parentNode.insertBefore(k,a)})
   (window, document, "script", "https://mc.yandex.ru/metrika/tag.js", "ym");
   ym(XXXXXXXX, "init", { clickmap:true, trackLinks:true, accurateTrackBounce:true });
</script>
<noscript><div><img src="https://mc.yandex.ru/watch/XXXXXXXX" style="position:absolute; left:-9999px;" alt="" /></div></noscript>
<!-- /Yandex.Metrika counter -->
```
