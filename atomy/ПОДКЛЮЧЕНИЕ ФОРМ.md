# 📲 Как подключить формы к Telegram (@IREN_13)

Цель: чтобы заявки с сайта приходили тебе **в Telegram** мгновенно.
Способ: бесплатный «мостик» на Google Apps Script — он хранит секретный ключ бота **на сервере Google**, а не на сайте (это безопасно).

Всё бесплатно. Времени — ~15 минут. Программировать не нужно, только копировать.

---

## Шаг 1. Создать Telegram-бота и получить ТОКЕН

1. В Telegram найди бота **@BotFather** (синяя галочка) и нажми **Start**.
2. Отправь команду: **/newbot**
3. Придумай имя бота (любое, напр. «Заявки ATOMY Ирина»).
4. Придумай username бота — он должен заканчиваться на **bot** (напр. `atomy_irina_bot`).
5. BotFather пришлёт **ТОКЕН** — длинную строку вида:
   `7123456789:AAHk......xYz`
   👉 Скопируй и сохрани её. Это секрет — никому не показывай.

## Шаг 2. Запустить своего бота и узнать свой CHAT_ID

1. Открой своего нового бота (ссылка от BotFather, напр. `t.me/atomy_irina_bot`) и нажми **Start** → отправь ему любое сообщение («привет»).
   *(Без этого бот не сможет тебе писать.)*
2. Узнай свой **CHAT_ID** (это просто номер):
   - Открой в браузере ссылку (вставь свой токен вместо `ТОКЕН`):
     `https://api.telegram.org/botТОКЕН/getUpdates`
   - В тексте найди `"chat":{"id":123456789` — **число после `"id":`** и есть твой CHAT_ID.
   - 🔁 Запасной способ: напиши боту **@userinfobot** — он пришлёт твой числовой ID.

## Шаг 3. Создать «мостик» на Google Apps Script

1. Зайди на **https://script.google.com** (под своим Google-аккаунтом) → **Новый проект**.
2. Удали весь текст в окне кода и вставь код из блока ниже (⬇️ раздел «Код для вставки»).
3. В коде замени:
   - `ВСТАВЬТЕ_ТОКЕН` → твой токен из Шага 1;
   - `ВСТАВЬТЕ_CHAT_ID` → твой номер из Шага 2.
4. Нажми **Сохранить** (значок дискеты).
5. Нажми **Развернуть → Новое развёртывание**.
   - Тип: выбери **Веб-приложение** (Web app).
   - «Выполнять от имени»: **Я**.
   - «У кого есть доступ»: **Все** (Anyone).
   - Нажми **Развернуть**, разреши доступ (Google спросит подтверждение — это нормально, твой же скрипт).
6. Скопируй **URL веб-приложения** — он заканчивается на **/exec**.

## Шаг 4. Вставить URL в сайт

Вариант А (сделаю я): пришли мне этот `/exec`-URL — я вставлю его в нужное место.

Вариант Б (сама): открой файл `site/js/main.js`, найди строку
```js
var FORM_ENDPOINT = '';
```
и вставь URL в кавычки:
```js
var FORM_ENDPOINT = 'https://script.google.com/macros/s/XXXXX/exec';
```

## Шаг 5. Проверить

1. Сайт должен быть **выложен в интернет** (или запущен через локальный сервер) — просто двойной клик по файлу для отправки не всегда срабатывает из-за защиты браузера.
2. Открой сайт, заполни любую форму, нажми «Отправить».
3. Тебе в Telegram должна прийти заявка. 🎉

## 🧩 Код для вставки (Шаг 3)

```javascript
// «Мостик»: форма сайта → Telegram. Заявки приходят тебе в чат с ботом.
var TOKEN   = 'ВСТАВЬТЕ_ТОКЕН';     // токен от @BotFather
var CHAT_ID = 'ВСТАВЬТЕ_CHAT_ID';   // твой числовой ID

function doPost(e) {
  try {
    var d = JSON.parse(e.postData.contents);
    var text =
      '🔔 Новая заявка с сайта ATOMY\n\n' +
      '👤 Имя: ' + (d.name || '—') + '\n' +
      '📞 Контакт: ' + (d.contact || '—') + '\n' +
      (d.goal ? ('🎯 Интерес: ' + d.goal + '\n') : '') +
      (d.message ? ('💬 Сообщение: ' + d.message + '\n') : '') +
      '📄 Страница: ' + (d.page || '—') + '\n' +
      '🕑 Время: ' + (d.time || '—');
    UrlFetchApp.fetch('https://api.telegram.org/bot' + TOKEN + '/sendMessage', {
      method: 'post',
      payload: { chat_id: CHAT_ID, text: text }
    });
  } catch (err) { /* игнорируем сбой, чтобы сайт не «падал» */ }
  return ContentService.createTextOutput('ok');
}
```

## ❓ Если что-то не пришло

- Проверь, что **нажала Start** у своего бота (Шаг 2.1).
- Проверь, что TOKEN и CHAT_ID вставлены **без лишних пробелов**, в кавычках.
- Проверь, что при развёртывании выбрано **«У кого есть доступ: Все»**.
- Пришли мне скриншот — помогу разобраться.

> 💡 Совет: пока мостик не настроен, формы работают в демо-режиме (показывают «Спасибо», но не отправляют) — сайт можно спокойно показывать.
